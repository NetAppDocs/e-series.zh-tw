= 在 E 系列 Linux 主機上設定 NVMe over TCP 啟動器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
TCP 環境中的 NVMe 啟動器組態包括安裝和設定 nvme-cli 套件、設定啟動器 IP 位址，以及在主機上設定 NVMe-oF 階層。

.開始之前
您必須執行最新的相容 RHEL 9、RHEL 10、SLES 15 或 SLES 16 Service Pack 作業系統。請參閱 https://mysupport.netapp.com/matrix["NetApp 互通性對照表工具"^]以取得完整的最新需求清單。

.步驟
. 如果您使用的是 HCA 內建的乙太網路驅動程式，請依下列步驟安裝  `nvme-cli` 套件：
+
*SLES 15 或 SLES 16*

+
[listing]
----

# zypper install nvme-cli
----
+
*RHEL 9 和 RHEL 10*

+
[listing]
----

# yum install nvme-cli
----
+
如果您正在使用 NVIDIA HCA 並希望使用外部 DOCA 驅動程式，請參閱 link:https://developer.nvidia.com/doca-downloads["NVIDIA 文件"] 以取得有關如何在此環境中正確安裝它的資訊。

. 對於 RHEL 9，請安裝網路指令碼：
+
* RHEL 9*

+
[listing]
----
# yum install NetworkManager-initscripts-updown
----
+

NOTE: RHEL 10 不提供網路腳本。

. 取得用於將主機設定為陣列的主機NQN。
+
[listing]
----
# cat /etc/nvme/hostnqn
----
. 在用於連接 NVMe over TCP 的乙太網路連接埠上設定 IPv4 IP 位址。為每個網路介面建立一個組態指令碼，其中包含該介面的不同變數。
+
此步驟所使用的變數取決於伺服器硬體和網路環境。這些變數包括「IPADDR」和「閘道」。以下是SLES和RHEL的範例指示：

+
*SLES 15*

+
建立包含下列內容的範例檔案 `/etc/sysconfig/network/ifcfg-eth4`。

+
[listing]
----
BOOTPROTO='static'
BROADCAST=
ETHTOOL_OPTIONS=
IPADDR='192.168.1.87/24'
GATEWAY='192.168.1.1'
MTU=9000
NAME='<adapter name>'
NETWORK=
REMOTE_IPADDR=
STARTMODE='auto'
----
+
然後、建立範例檔案「etc/sysconfig/network/ifcfg/eth5」：

+
[listing]
----
BOOTPROTO='static'
BROADCAST=
ETHTOOL_OPTIONS=
IPADDR='192.168.2.87/24'
GATEWAY='192.168.2.1'
MTU=9000
NAME='<adapter name>'
NETWORK=
REMOTE_IPADDR=
STARTMODE='auto'
----
+
*RHEL 9、RHEL 10 或 SLES 16*

+
使用 `nmtui` 用於啟動和編輯連線的工具。以下是範例檔案 `/etc/NetworkManager/system-connections/eth4.nmconnection` 此工具將產生：

+
[listing]
----

[connection]
id=eth4
uuid=<unique uuid>
type=ethernet
interface-name=eth4

[ethernet]
mtu=9000

[ipv4]
address1=192.168.1.87/24
method=manual

[ipv6]
addr-gen-mode=default
method=auto

[proxy]
----
+
以下是範例檔案 `/etc/NetworkManager/system-connections/eth5.nmconnection` 此工具將產生：

+
[listing]
----

[connection]
id=eth5
uuid=<unique uuid>
type=ethernet
interface-name=eth5

[ethernet]
mtu=9000

[ipv4]
address1=192.168.2.87/24
method=manual

[ipv6]
addr-gen-mode=default
method=auto

[proxy]
----
. 啟用網路介面：
+
[listing]
----

# nmcli connection up eth4
# nmcli connection up eth5
----
. 在主機上設定 NVMe-oF 階層。在 `/etc/modules-load.d/`下建立下列檔案，以載入 `nvme_tcp`核心模組，並確保核心模組始終處於啟用狀態，即使在重新開機後也是如此：
+
[listing]
----

# cat /etc/modules-load.d/nvme_tcp.conf
  nvme_tcp
----
. 重新啟動主機。
+
.. 或者，您可以執行此命令來載入 `nvme_tcp`核心模組，而無需重新開機：
+
[listing]
----

# modprobe nvme_tcp
----


. 驗證  `nvme_tcp` 核心模組是否已載入，請執行此命令：
+
[listing]
----
# lsmod | grep nvme
nvme_tcp               45056  0
nvme_fabrics           24576  1 nvme_tcp
nvme_core             114688  5 nvme_tcp,nvme_fabrics
t10_pi                 16384  2 sd_mod,nvme_core
----
+
