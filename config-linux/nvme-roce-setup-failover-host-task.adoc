= 在 E 系列的主機上設定容錯移轉 - Linux （ NVMe over roce ）
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要提供儲存陣列的備援路徑、您可以設定主機執行容錯移轉。

.開始之前
請參閱 https://mysupport.netapp.com/matrix["NetApp 互通性對照表工具"^]以確保安裝任何必要的更新，因為初始版本中未提供的 SLES 或 RHEL 版本可能需要重要的錯誤修復。

.關於這項工作
對於 SLES 15、SLES 16、RHEL 9 和 RHEL 10，預設啟用原生 NVMe 多路徑，無需額外配置。

.接下來呢？
啟用原生 NVMe 多路徑後，link:nvme-roce-access-physical-targets-concept.html["從主機存取 E-Series 目標的 NVMe 磁碟區"]。
