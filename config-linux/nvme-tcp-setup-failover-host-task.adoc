= 在 E 系列 Linux NVMe over TCP 主機上設定故障轉移
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要提供儲存陣列的備援路徑、您可以設定主機執行容錯移轉。

.開始之前
請參閱 https://mysupport.netapp.com/matrix["NetApp 互通性對照表工具"^]以確保安裝任何必要的更新，因為初始版本中未提供的 SLES 或 RHEL 版本可能需要重要的錯誤修復。

.關於這項工作
對於 SLES 15、SLES 16、RHEL 9 和 RHEL 10，預設啟用原生 NVMe 多路徑，無需額外配置。



[[configure-nvme-io-policy]]
== 設定 NVMe I/O 原則

.關於這項工作
Linux NVMe 原生多重路徑預設可能採用  `numa` I/O 原則。對於 E 系列 / EF 系列 NVMe-over-Fabrics 組態，建議的 I/O 原則為  `round-robin`，這會將 I/O 平均分配到所有可用路徑上。

.步驟
. 驗證目前的 NVMe I/O 原則：
+
[listing]
----
# cat /sys/module/nvme_core/parameters/iopolicy
numa
----
. 使用下列其中一種方法來設定 `round-robin` I/O 原則：
+
** *持久化（建議）* — 建立 udev 規則檔案：
+
.<code>/etc/udev/rules.d/71-nvme-io-policy.rules</code>
[listing]
----
ACTION=="add|change", SUBSYSTEM=="nvme-subsystem", ATTR{iopolicy}="round-robin"
----
+
然後重新載入並套用規則：

+
[listing]
----
udevadm control --reload
udevadm trigger --subsystem-match=nvme-subsystem
----
** *開機時全域設定* — 將下列內核參數新增至您的開機載入程式組態：
+
[listing]
----
nvme_core.iopolicy=round-robin
----
** *非持續性（線上，無 I/O 中斷）* — 無需重新開機即可立即套用：
+
[listing]
----
echo "round-robin" > /sys/class/nvme-subsystem/nvme-subsys0/iopolicy
----
+

NOTE: 此設定在重新開機後不會保留。
